# PanelLeadsIndo

Proyecto de analítica de Leads de Universidad Indoamérica.

## Objetivo

Migrar el reporte original `pnl_Leads_MKT.pbix` a un proyecto Power BI (`PBIP`) versionable por Git y evolucionarlo hacia un **Lead Intelligence Dashboard**.

El repositorio tendrá como fuente principal:

- PBIR para la definición del reporte.
- TMDL para el modelo semántico.
- DAX versionado como código.
- Documentación de arquitectura, KPIs y reglas de negocio.
- Scripts y validaciones auxiliares.

> El archivo PBIX original se considera un artefacto de migración/respaldo, no la fuente de verdad final.
